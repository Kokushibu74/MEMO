# MEMO v1.5
A multi-AI WhatsApp assistant with automatic fallback, memory, and Bangla/Banglish support.

## Features
- Gemini
- ChatGPT
- Claude
- Grok
- DeepSeek
- Groq
- Automatic AI fallback
- Conversation memory
- Bangla, Banglish and English support
- WhatsApp AI assistant

## Installation

```bash
bash ~/memo/requirements.txt
```

## Start

```bash
memo
```
